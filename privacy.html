Política de Privacidade do ReadFlow

Última atualização: novembro de 2026

1. Introdução

O ReadFlow é uma aplicação destinada a organizar e acompanhar leituras. Esta política explica como os dados são tratados.

2. Dados e armazenamento

A aplicação pode armazenar dados relacionados com a utilização e organização das leituras. Os dados são utilizados apenas para disponibilizar as funcionalidades da aplicação.

3. Google Drive

O ReadFlow pode utilizar a API Google Drive, através do âmbito drive.appdata, para guardar e sincronizar dados privados da aplicação. O acesso limita-se à área de dados da aplicação no Google Drive.

4. Partilha de dados

O ReadFlow não vende dados pessoais nem os utiliza para publicidade.

5. Segurança

São utilizadas as funcionalidades de segurança disponibilizadas pelos serviços integrados.

6. Contacto

Para questões relacionadas com a privacidade, contacta o responsável pelo ReadFlow através do endereço de contacto disponibilizado na distribuição da aplicação.
